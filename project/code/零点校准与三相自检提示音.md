# 零点校准与三相自检提示音说明

执行零点校准时，驱动板会先进行三相桥臂鸣响自检，然后执行编码器零点校准和参数保存。各组声音含义如下。

| 听到的声音 | 含义 |
|---|---|
| C5 一声 | A 相桥臂自检 |
| E5 两声 | B 相桥臂自检 |
| G5 三声 | C 相桥臂自检 |
| D5、E5、F5、G5、A5、B5、C6 快速上升七音阶 | 编码器零点校准成功，编码器方向、极对数和机械零偏已得到有效结果 |
| C6、B5、A5、G5、F5、E5、D5 快速下降七音阶 | 校准参数已成功保存到 Flash |

## 结果判断

- 正常完成时，应先听到一声、两声、三声三组桥臂自检音，然后听到上升七音阶和下降七音阶。
- 某组桥臂自检音缺失、明显偏弱或异常时，应停止校准并检查对应相的 MOS、预驱、相线和供电。
- 三相自检完成后没有上升七音阶，表示本次零点校准没有成功，不能认为当前零点参数有效。
- 听到上升七音阶但没有下降七音阶，表示零点校准成功，但参数没有成功保存到 Flash，重新上电后可能丢失。

三相自检采用人工听音判断，不会自动检测并上报某一相通过或失败。
