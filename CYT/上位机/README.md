# FOC_L

用于当前 `FOC_L` 工程的 Windows 电机调试上位机。首版提供完整的仿真设备，可在下位机通信协议完成前检查工作流和界面。

## 已完成功能

- 电机连接、使能、停止、急停和急停复位
- 驱动板软件复位并自动重新同步设备参数
- 电压、电流/转矩、速度、位置四种控制模式
- 无感 FOC 的 HFI、SMO、PLL 参数分组，HFI 暂留，SMO/PLL 参数可在线调节
- 电流环、速度环、位置环和 SMO/PLL 使用可调边界滑块在线调参，滑块左右边界支持断电保存
- 开环、电流和速度目标使用可调边界滑块，位置目标使用首尾相接的圆盘实时给定，圆盘将 0° 与 360° 作为同一点，目标滑块边界支持断电保存
- 转速、电流、电压、角度、温度、PWM 等实时状态
- SMO 实际/估算 Iα、Iβ、Iq 误差、反电动势与 PLL 角度、角速度、相位误差示波器通道
- 示波器目标机械角度观测通道，可与实际机械角度对比
- 50000 点/通道环形缓冲示波器、按勾选通道订阅高速流、可见区峰谷抽稀、双点时间差测量、暂停显示和 CSV 导出
- 左侧菜单独立切换实时工作台和串口诊断
- Windows COM 口扫描、串口配置、协议帧过滤与手动发送
- 选择下位机内置乐曲并通过圆形播放按钮启动，播放完成后自动停止
- 事件和故障操作日志
- 控制、示波器和通道窗口根据可用空间自动调整尺寸，同时保留拖拽调整
- `Ctrl + +` 放大界面，`Ctrl + -` 缩小界面

## 启动

首次运行：

```powershell
cd "CYT\上位机"
npm install
npm run build
npm start
```

开发模式：

```powershell
npm run dev
```

仅在浏览器中预览界面：

```powershell
npm run dev:web
```

## 当前限制

上位机通过 USB 转串口连接电机驱动板，CAN 留给 MCU 之间通信。串口协议实现位于 `electron/serial/protocol.cjs`，协议说明见 `docs/SERIAL_PROTOCOL.md`。当前下位机复用 `debug_init()` 的 UART0（460800 bit/s、P00_1/P00_0），连接期间不要在该串口输出 `printf` 文本。示波器全部已勾选设备通道固定 1 ms 采样，包括实际转速、实际 Iq、母线电压和机械角度；下位机在同一采样点读取所选字段，不再按字段数量自动降低采样率。当前波特率和 80% 带宽预算下最多允许同时勾选 8 个设备通道，超额选择或带宽不足的串口配置修改会被拒绝并提示。连接有效时电机失能仍保持采样，控制通信超时才暂停观测流。需要同步更新下位机固件；基础遥测仅更新状态卡，不作为已选设备通道的低速波形回退。

`foc_voice` 音乐模式负责选择下位机内置乐曲并发送播放命令。乐曲节拍和实际播放均由下位机负责；播放会话号用于防止 20 Hz 控制心跳重复触发歌曲，播放状态位用于在乐曲结束后自动关闭上位机使能。
