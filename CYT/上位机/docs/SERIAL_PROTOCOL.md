# FOC-UART/1.0 串口协议草案

电脑通过 USB 转串口连接电机驱动板，CAN 继续用于 MCU 之间通信。该文档定义上位机和下位机共同使用的串口帧格式、收发流程和安全状态机。

## 串口配置

- 默认波特率：460800 bit/s
- 数据格式：8-N-1
- 无硬件流控
- 多字节整数和浮点数采用小端序
- 浮点数采用 IEEE 754 单精度格式
- 当前下位机复用 `debug_init()` 的 UART0（P00_1/P00_0），禁止在连接期间混入 `printf` 文本日志

当前阶段默认使用 460800 bit/s 完成控制和调参。基础遥测保持 40 Hz，用于状态卡；示波器通过 `0x17` 订阅全部已勾选的设备字段，下位机使用扩展批次帧返回，采样周期固定为 1 ms。上位机在勾选通道和修改串口配置时，以串口速率的 80% 检查带宽；超额时保留原选择或原配置并提示，不自动降低采样率。已选字段在同一采样点读取，未选字段不进入高速采样和传输。

## 通用帧格式

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 帧头 `0xAA` |
| 1 | `uint8` | 帧头 `0x55` |
| 2 | `uint8` | 协议版本，当前为 1 |
| 3 | `uint8` | 帧类型 |
| 4 | `uint16` | 递增序号 |
| 6 | `uint16` | 负载长度 N，最大 1024 |
| 8 | `uint8[N]` | 负载 |
| 8+N | `uint16` | CRC16-Modbus |

CRC 从版本字段开始计算，到负载最后一个字节结束，不包含 `AA 55` 帧头和 CRC 字段本身。接收端必须按长度取帧，并在 CRC 错误后重新搜索帧头。

## 控制命令负载

`0x10`，16 字节：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 驱动模式：0 开环、1 编码器 FOC、2 `foc_voice` 音乐 |
| 1 | `uint8` | bit0 使能、bit1 方向/回正方式、bit2 急停 |
| 2 | `uint8` | FOC 子模式：0 电压、1 电流、2 速度、3 位置 |
| 3 | `uint8` | 普通模式保留；音乐模式为曲目编号 |
| 4 | `float32` | 普通模式主目标：开环 Uq、FOC 电流/速度目标绝对值，或位置模式目标机械角度（°） |
| 8 | `float32` | 普通模式次目标：开环 Angle 或 FOC Ud/Id |
| 12 | `uint16` / `float32` | 开环角度步进；FOC 电流模式为电流环带宽（Hz），其后 2 字节保留；FOC 速度模式为速度斜坡速率（rpm/s，范围 1~100000）；位置模式保留 |

速度模式下，界面使用目标转速的正负号表示旋转方向。上位机下发目标转速绝对值和速度斜坡速率，并按照目标符号自动设置方向位。下位机在 1 kHz 速度环中生成斜坡目标，启动以及运行中修改目标转速时均按该速率平滑变化；停止和急停仍立即关闭输出。电机运行时修改速度斜率通过控制帧实时生效，停止时修改则同时通过参数帧写入，确保下一次参数回读保持一致。

## FOC 环路参数

读取参数使用 `0x11`，负载长度为 0。下位机返回 `0x12` 参数负载；上位机写入时也使用相同的 `0x12` 负载布局，长度为 44 字节：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint16` | 电流环带宽，Hz |
| 2 | `uint16` | 保留，写 0 |
| 4 | `float32` | 速度斜坡速率，rpm/s，参数未配置时为 0，配置范围 1~100000 |
| 8 | `float32` | 速度环 KP |
| 12 | `float32` | 速度环 KI |
| 16 | `float32` | 速度环积分项限幅，A，最大 5 A |
| 20 | `float32` | AB 滤波器带宽，Hz，范围 1~500 Hz |
| 24 | `float32` | 位置环 KP |
| 28 | `float32` | 位置环到位线性软化范围，度，范围 0~180，不大于角度死区时关闭 |
| 32 | `float32` | 位置环到位速度死区，rpm，范围 0~100，固件默认 20，写 0 时关闭 |
| 36 | `float32` | 位置环输出限幅，rpm |
| 40 | `float32` | 位置环角度死区，度，范围 0~180 |

下位机校验参数后使用短临界区整组应用，支持在电机运行中调整电流环、速度环和位置环参数。上位机拖动调节控件时按 80 ms 合并连续变化，只发送该时间段内的最新参数。上位机离线时速度斜率保持 0，不预置设备参数；连接后先读取参数，界面以回读结果覆盖离线初值，速度斜率也采用下位机回读值。参数未同步前不得启动有感 FOC。全部有感 FOC 子模式还必须具备有效编码器零点参数，否则下位机拒绝使能并关闭输出。

无感观测器参数使用独立的 `0x13/0x23` 帧，负载长度为 16 字节，按顺序为 `smoKSlide`、`smoBoundaryCurrent`、`smoFilterBandwidth` 和 `pllBandwidth`，全部为 `float32`，两个带宽字段的单位均为 Hz。PLL 阻尼比固定为 `0.707`，下位机将 `pllBandwidth` 作为自然频率，按 `ωn=2π·pllBandwidth`、`Kp=2·0.707·ωn`、`Ki=ωn²` 自动生成 PI 增益；电角速度和积分项限幅为固件固定保护配置，不作为在线调参项。默认 PLL 带宽为 20 Hz，通常从 10~30 Hz 开始，并建议不超过 SMO 反电动势滤波带宽的五分之一。带宽增大时锁定更快但角度和速度噪声更大，带宽减小时输出更平滑但加减速跟随变慢。HFI 当前预留，不发送参数。独立帧保留了原有 44 字节有感参数帧的兼容性。SMO/PLL 参数支持运行中调整；连续调整已有 SMO 参数时保留估算电流，首次启用或停机写入时重新初始化观测器状态。参数当前只写入下位机运行时 RAM，不写 Flash；每次上电先使用固件初始化值，连接同步时上位机以下位机回传值覆盖界面参数。

无感观测模式仍会读取编码器角度并计算 `speedActual`，该值仅作为上位机的实际转速诊断量，用于和 PLL 估算转速对比，不参与无感控制反馈。

电流和速度模式不再单独选择方向，目标值非负时 bit1 为 0，目标值为负时 bit1 为 1；开环和电压模式下 bit1 仍由方向选择控制。位置模式下该位改为回正方式：bit1 为 0 时按最近距离回正，也是上位机默认选项；bit1 为 1 时连续累计位置模式建立参考后的偏转角度，并沿偏转路径的反方向原路回正。例如顺时针偏转 270 度后，原路回正模式会逆时针返回 270 度，最近距离模式则顺时针返回 90 度。

位置环反馈使用扣除编码器零偏并修正编码器方向后的单圈机械角，按 `uint16` 单圈计数线性映射为 `0~360` 度，`360` 度与 `0` 度等价。最近距离误差展开到 `-180~180` 度；原路回正误差通过相邻位置环采样的最短角度增量连续累加，因此跨越 `0/360` 度时不会丢失偏转圈数。误差绝对值不超过角度死区时，位置环输出速度目标为 0；超出死区时先从误差绝对值中扣除死区宽度，得到有效误差。软化范围大于角度死区时，在角度死区边界至软化范围之间，位置 KP 比例按照 `|有效误差| / (软化范围 - 角度死区)` 从 0 线性恢复到完整增益；软化范围小于等于角度死区时关闭软化。

到位速度死区只在位置误差已经进入角度死区后生效。此时若实际转速仍高于速度死区，速度环继续以零速目标制动；实际转速进入速度死区后，清除速度 PI 状态并令 `Iq` 目标为 0，避免编码器零速噪声持续激励电机。位置误差离开角度死区后立即恢复正常位置和速度控制。

速度环 PI 输出由下位机按照 `sqrt(Imax² - Id²)` 计算出的 q 轴可用电流动态限幅，并将饱和误差反算给积分器。AB 滤波器带宽在速度环参数区设置，用于编码器转速反馈滤波。

上位机连接物理串口后以 20 Hz 周期发送该命令，同时兼作控制心跳。急停、停止等状态变化时不应等待下一周期，应立即额外发送一帧。

音乐模式不再使用单频频率和幅值参数。驱动模式为 2 时，偏移 3 为通过 `0x14` 乐曲列表获得的曲目编号；偏移 4 改按 `uint32` 解释为播放会话号，偏移 8 和 12 置零。上位机每次按下播放按钮都递增会话号。下位机仅在使能由关闭变为打开、曲目编号改变或收到新的会话号时从头播放；20 Hz 心跳中的相同会话号只能保活，不得重新触发曲目。乐曲节拍和播放过程全部由下位机负责，上位机不计算播放进度。

## 零点校准命令

`0x15`，负载长度为 0。下位机收到合法帧后先停止当前控制输出，再在主循环中执行桥臂自检和编码器零点校准。该命令是一次性触发命令，不随控制心跳重复发送；上位机仅允许在设备已连接、电机未运行且急停未锁定时发送。

## 驱动板软件复位命令

`0x16`，负载长度为 0。下位机收到合法帧后先停止控制输出，再触发 CM4 系统软件复位；对当前 CM4 电机控制应用等效于按键重新启动，复位原因记录为软件复位。该命令不会修改 Flash 中保存的电机参数。上位机发送复位前必须先发送失能控制帧，避免驱动板重启后因控制心跳残留自动重新启动电机。

## 内置乐曲列表

上位机打开物理串口后发送一帧负载长度为 0 的 `0x14` 查询。下位机按曲目编号顺序逐首返回 `0x14` 响应，每首乐曲占一帧：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 曲目编号，从 1 开始连续编号 |
| 1 | `uint8` | 下位机内置曲目总数 |
| 2 | `uint8` | UTF-8 曲名的字节数 M，当前最大 48 |
| 3 | `uint8[M]` | UTF-8 编码曲名，不带结尾 `\0` |

同一次查询的全部响应必须携带相同的曲目总数。上位机收齐全部编号后才一次性替换乐曲下拉列表；未收到响应或响应不完整时继续显示兼容列表。因此以后新增下位机曲目时，只需在下位机音乐表中维护曲名和旋律，上位机在重新连接后会自动同步。

## 基础遥测负载

`0x20`，24 字节。基础遥测只服务于工作台顶部四个状态卡，其余示波器字段必须通过勾选后的高速观测流发送：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 电机状态 |
| 1 | `uint8` | 当前控制模式 |
| 2 | `uint8` | 当前最高优先级故障 |
| 3 | `uint8` | 状态标志 |
| 4 | `uint32` | 设备运行时间，ms |
| 8 | `float32` | 实际转速，rpm |
| 12 | `float32` | 实际 Iq，A |
| 16 | `float32` | 母线电压，V |
| 20 | `float32` | 校正后的机械角度，°，范围 0~360 |

下位机仍可发送旧版 56 字节基础遥测，上位机保留兼容解码；新版下位机使用 24 字节格式减少固定串口占用。

状态标志中 bit0 表示控制输出使能，bit1 表示电流采样已校准，bit2 表示下位机正在播放音乐，bit3 表示最近一次运行中的停机由控制帧超时触发，bit4 表示本次上电后 UART 软件接收缓冲曾溢出。bit3 在下一次成功使能时清除；bit4 保持到下位机复位，仅能证明发生过软件缓冲溢出，不能单独确定停机原因，也不覆盖 UART 硬件 FIFO 丢字节。旧版固件的 bit3、bit4 均为 0，不能据此排除超时或丢帧。上位机观察到 bit2 从 1 变为 0 后，应立即发送失能控制帧并将播放按钮恢复为待机状态。

### 高速波形负载

`0x21`，36 字节单采样负载：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint32` | 设备运行时间，ms |
| 4 | `float32` | A 相电流，A |
| 8 | `float32` | B 相电流，A |
| 12 | `float32` | C 相电流，A |
| 16 | `float32` | PWM 重构 D 轴电压，V |
| 20 | `float32` | PWM 重构 Q 轴电压，V |
| 24 | `float32` | PWM A，占空比百分比 |
| 28 | `float32` | PWM B，占空比百分比 |
| 32 | `float32` | PWM C，占空比百分比 |

当前上位机连接后发送 13 字节 `0x17` 扩展配置，所有驱动模式都通过 `0x27` 返回当前勾选且不属于顶部四项的字段。高速观测只在控制输出使能后发送，失能状态仅保留基础遥测，避免空载时持续占用串口和界面资源。未收到过 `0x17` 的旧版上位机仍可在开环及音乐模式接收每 10 ms 一帧的 `0x21` 普通波形，在有感及无感 FOC 模式接收每 20 ms 一帧的 `0x22` 兼容观测波形。3/7 字节旧配置继续对应 `0x25` 毫秒批次，8 字节配置继续对应 `0x26` 自适应批次。基础遥测仍按 25 ms 发送，各类帧共用帧序号，接收端应按负载中的设备时间戳排序。

实际 Id/Iq 在控制中断中持续更新并进入高速流；无感模式下使用编码器电角度进行 Park 变换，仅作为诊断数据，不参与无感控制反馈。Ud/Uq 不读取可能停留在旧值的电流环输出缓存，而是根据实时三相 PWM 占空比与母线电压重构：开环模式使用开环电角度，其余模式使用编码器电角度。转矩值使用 1 kHz 缓存结果，采集高速流时不再重复执行估算。

`0x22` SMO/PLL 观测波形负载为 56 字节，字段如下：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint32` | 设备运行时间，ms |
| 4 | `float32` | SMO 估算 Iα，A |
| 8 | `float32` | SMO 估算 Iβ，A |
| 12 | `float32` | SMO 未滤波 Eα，V |
| 16 | `float32` | SMO 未滤波 Eβ，V |
| 20 | `float32` | SMO 滤波 Eα，V |
| 24 | `float32` | SMO 滤波 Eβ，V |
| 28 | `float32` | PLL 估算机械角度，° |
| 32 | `float32` | PLL 估算电角度，° |
| 36 | `float32` | PLL 估算电角速度，rad/s |
| 40 | `float32` | PLL 相位误差，° |
| 44 | `float32` | 实际 Iα，A |
| 48 | `float32` | 实际 Iβ，A |
| 52 | `float32` | SMO Iq 误差（实际 Iq - 估算 Iq），A |

其中角度和相位误差单位为度，电角速度单位为 `rad/s`。PLL 对反电动势正交分量进行幅值归一化鉴相，并根据转向消除正反转的反电动势极性差异；输出角度包含按 SMO 一阶低通带宽和当前估算电角速度计算的动态相位补偿。实际 Iα/Iβ 来自当前采样电流的 Clarke 变换，用于与 SMO 估算电流对比；Iq 误差使用编码器电角度将两组 α/β 电流分别变换到同一 dq 坐标系后计算，定义为实际 Iq 减去估算 Iq。上位机将该帧与普通高速波形合并到同一示波器缓冲区。


### 紧凑观测流

`0x17` 配置帧支持 3 字节、7 字节、8 字节和 13 字节四种负载。当前上位机发送 13 字节格式，以覆盖示波器中的全部设备通道：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint64` | 观测字段位图 |
| 8 | `uint8` | 周期字段，上位机发送 1，下位机对扩展订阅固定使用 1 ms |
| 9 | `uint32` | 兼容保留的带宽字段，上位机发送所选波特率的 80%，扩展订阅不据此降速 |

旧版 3 字节格式如下：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint16` | 观测字段位图 |
| 2 | `uint8` | 请求采样周期，单位为 ms，当前固定为 1 |

7 字节格式在 3 字节格式后增加 `uint32` 可用带宽；8 字节格式使用 `uint16` 控制节拍周期和 `uint32` 可用带宽。三种旧格式供兼容工具使用，仍按以下公式调整实际周期；当前上位机使用的 13 字节扩展订阅固定为 1 ms，不使用此降速规则。位图为 0 时关闭观测高速流，但不影响 `0x20` 基础遥测。

```text
最小周期(控制节拍) = ceil(完整批次帧字节数 × 10 × 20000
                            / (可用带宽 × 单帧采样数))
```

所有已勾选的设备通道均进入 1 ms 高速流，包括实际转速、实际 Iq、母线电压、机械角度和 PLL 角度。默认 460800 bit/s、8-N-1 和 80% 带宽预算下，上位机最多允许同时选择 8 个设备通道；全选、模式推荐、单通道切换以及串口配置修改均检查此限制。目标机械角由上位机生成，不占设备通道带宽。带宽检查使用实际批次点数，不能假定所有批次都能装满 8 点：

```text
批次点数 = min(8, floor((256 - 14) / (4 × 设备通道数)))
所需带宽 = (10 + 14 + 4 × 设备通道数 × 批次点数) × 每字节串口位数 × 1000 / 批次点数
```

连接有效且存在订阅时，电机失能也继续采集和发送；控制通信超时则暂停观测流。切换订阅后，以当前设备时间重新建立采样时基。基础遥测不填充已选设备通道的示波器曲线；高速流中断超过 200 ms 后仅让状态卡恢复基础遥测。此规则需要同步更新下位机固件，旧固件缺失的高速字段不再用低速数据冒充。

字段始终按 bit0 到 bit33 的顺序紧密排列。目标机械角由上位机控制命令生成，不占用下位机订阅位。`0x24` 是旧版单点紧凑帧，只支持 bit0 到 bit15，负载前 6 字节为毫秒时间戳和字段位图：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint32` | 设备运行时间，ms |
| 4 | `uint16` | 本帧实际字段位图 |
| 6 | `float32[]` | 已选字段值，按位号升序排列 |

`0x25`为兼容的毫秒批次帧，固定负载依次为`uint32`基础时间戳、`uint16`字段位图、`uint8`周期毫秒数和`uint8`采样数，随后排列连续采样值。

`0x26`为高分辨率自适应批次帧，固定负载如下：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint32` | 第一组采样的20 kHz时间戳 |
| 4 | `uint16` | 本帧实际字段位图 |
| 6 | `uint16` | 相邻采样周期，单位为20 kHz控制节拍 |
| 8 | `uint8` | 本帧连续采样数 |
| 9 | `float32[]` | 各采样的已选字段值 |

`0x27` 为当前上位机使用的扩展毫秒批次帧，固定负载如下：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint32` | 第一组采样的设备毫秒时间戳 |
| 4 | `uint64` | 本帧实际字段位图 |
| 12 | `uint8` | 相邻采样周期，单位为 ms |
| 13 | `uint8` | 本帧连续采样数 |
| 14 | `float32[]` | 各采样的已选字段值 |

单帧最多合并 8 组采样，负载最长 256 字节。全部已选设备字段在下位机同一采样点内读取，其中转速和估算转矩读取各自的 1 kHz 缓存结果。上位机对已收到高速样本的订阅字段忽略基础遥测中的重复值，避免不同采样时刻的数据交替覆盖；串口和 IPC 分批只影响到达上位机的延迟，不改变设备时间戳及相邻点的真实 1 ms 间隔。

## 下位机安全要求

- 连续 200 ms 未收到合法控制帧时关闭 PWM
- CRC、长度或协议版本错误的帧不得执行
- 急停优先级高于其他所有命令
- 参数范围必须由下位机再次检查
- PWM 频率、死区、极对数等参数只允许在电机失能时修改
- 接收中断只负责写入环形缓冲区，解析和命令处理放在主循环或低优先级任务
- FOC 电流环中断只写遥测缓冲区，不直接阻塞发送串口数据
