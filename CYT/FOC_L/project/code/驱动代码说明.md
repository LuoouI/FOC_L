# CYT2BL3 FOC 电机驱动代码说明

## 1. 项目简介

本目录为基于 CYT2BL3 微控制器的三相无刷电机 FOC 驱动代码，主要用于电机控制算法验证、硬件调试和上位机联调。

当前代码包含以下功能：

- SVPWM 三相 PWM 输出
- Clarke/Park 变换及反变换
- 电流环、速度环和位置环控制
- 编码器角度采集、方向修正和零点校准
- ADC 电流采样及采样值校准
- 串口控制协议和运行状态回传
- 电机参数 Flash 保存
- 基于 FOC 的音乐播放实验功能

本项目当前属于实验和开发版本，使用前应先进行限流供电、空载测试和急停测试。

## 3. 控制流程

系统启动后，主函数依次完成 GPIO、ADC、TCPWM、PWM、编码器、Flash 参数和通信模块初始化。

电机运行时，PWM 中断负责高速控制任务：

1. 读取 ADC 电流采样值。
2. 进行电流偏置修正和坐标变换。
3. 执行电流环 PI 控制。
4. 根据控制模式执行速度环或位置环。
5. 计算电压矢量并生成 SVPWM 占空比。
6. 更新三相 PWM 输出和运行状态缓存。

通信接收和参数处理在较低优先级的主循环中执行，避免在高速控制中断中进行阻塞操作。

## 4. 控制模式

当前协议支持以下驱动模式：

| 模式 | 说明 |
|---|---|
| 开环模式 | 直接控制电压和电角度，适合初步检查相序和硬件输出 |
| 编码器 FOC | 使用编码器反馈进行电流、速度或位置控制 |
| 音乐模式 | 使用 FOC 产生设定频率和幅值的旋转磁场 |

有感 FOC 启动前应确认编码器方向、零点偏移、电流采样极性和电机相序均正确。

## 5. 参数说明

主要控制参数位于 `Motor_Control` 和 `Foc_Protocol` 模块中，包括：

- 电流环带宽
- 速度环 KP、KI
- 速度目标和速度斜坡
- 位置环 KP
- 位置角度死区和速度死区
- 位置环输出限幅
- AB 滤波器带宽
- 编码器零点偏移

参数修改应在电机失能状态下进行。上位机写入参数后，下位机应完成范围检查，确认有效后再保存到 Flash。

## 6. 通信接口

上位机默认通过 UART 连接驱动板，串口参数为：

- 波特率：115200 bit/s
- 数据位：8
- 校验位：无
- 停止位：1
- 多字节数据：小端序
- 浮点数：IEEE 754 单精度

完整帧格式和负载定义见上位机目录中的 `docs/SERIAL_PROTOCOL.md`。

控制帧包含使能、急停、控制模式、目标值和参数等信息。连续一段时间未收到合法控制帧时，驱动应关闭 PWM 输出。急停状态的优先级高于普通控制命令。

## 7. 调试建议

建议按照以下顺序进行调试：

1. 不连接电机，确认芯片能够正常启动和下载。
2. 检查三相 PWM 波形、频率、互补关系和死区时间。
3. 检查 ADC 触发时刻和电流采样偏置。
4. 低压限流条件下进行开环低幅值测试。
5. 检查编码器计数方向和机械角度变化。
6. 执行编码器零点校准。
7. 先调电流环，再调速度环，最后调位置环。
8. 逐步提高母线电压和目标转速。

## 8. 安全注意事项

- 首次上电必须使用限流电源，禁止直接接入未经确认的高压母线。
- 电机运行时应确保转子和负载不会造成人身伤害。
- 急停功能必须在实际硬件上验证，不能只依赖上位机按钮。
- 电流采样极性、编码器方向或电机相序错误时，不得继续提高电压和电流。
- 本代码未声明适用于人身安全、汽车、航空或其他安全关键设备。
- 使用者需要根据自己的功率器件、栅极驱动器和电源结构补充过流、过压、欠压、过温和硬件关断保护。
