# FOC-UART/1.0 串口协议草案

电脑通过 USB 转串口连接电机驱动板，CAN 继续用于 MCU 之间通信。该文档定义上位机已经实现的串口帧格式，下位机源码恢复后需要实现对应的收发和安全状态机。

## 串口配置

- 默认波特率：115200 bit/s
- 数据格式：8-N-1
- 无硬件流控
- 多字节整数和浮点数采用小端序
- 浮点数采用 IEEE 754 单精度格式
- 当前下位机复用 `debug_init()` 的 UART0（P00_1/P00_0），禁止在连接期间混入 `printf` 文本日志

当前阶段统一使用 115200 bit/s 完成控制和调参。默认 100 Hz 波形帧与 40 Hz 基础遥测合计约占用 7.24 kB/s，可在 115200 bit/s 下稳定传输。需要进一步提高采样率时，必须将上位机和下位机同时切换到更高波特率。

## 通用帧格式

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 帧头 `0xAA` |
| 1 | `uint8` | 帧头 `0x55` |
| 2 | `uint8` | 协议版本，当前为 1 |
| 3 | `uint8` | 帧类型 |
| 4 | `uint16` | 递增序号 |
| 6 | `uint16` | 负载长度 N，最大 1024 |
| 8 | `uint8[N]` | 负载 |
| 8+N | `uint16` | CRC16-Modbus |

CRC 从版本字段开始计算，到负载最后一个字节结束，不包含 `AA 55` 帧头和 CRC 字段本身。接收端必须按长度取帧，并在 CRC 错误后重新搜索帧头。

## 帧类型

| 类型 | 方向 | 用途 |
|---|---|---|
| `0x01` | 双向 | 握手、固件和能力信息 |
| `0x02` | 双向 | 心跳 |
| `0x10` | 上位机 → 驱动板 | 电机控制命令 |
| `0x11` | 上位机 → 驱动板 | 读取参数 |
| `0x12` | 双向 | 写入参数和回读确认 |
| `0x14` | 双向 | 查询和返回下位机内置乐曲列表 |
| `0x15` | 上位机 → 驱动板 | 编码器零点校准 |
| `0x20` | 驱动板 → 上位机 | 基础遥测 |
| `0x21` | 驱动板 → 上位机 | 可订阅高速波形 |
| `0x30` | 驱动板 → 上位机 | 故障事件和快照 |
| `0x31` | 驱动板 → 上位机 | 结构化运行日志 |

## 控制命令负载

`0x10`，16 字节：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 驱动模式：0 开环、1 编码器 FOC、2 `foc_voice` 音乐 |
| 1 | `uint8` | bit0 使能、bit1 方向/回正方式、bit2 急停 |
| 2 | `uint8` | FOC 子模式：0 电压、1 电流、2 速度、3 位置 |
| 3 | `uint8` | 普通模式保留；音乐模式为曲目编号 |
| 4 | `float32` | 普通模式主目标：开环 Uq 或 FOC 主目标；电流、速度模式下发送目标绝对值 |
| 8 | `float32` | 普通模式次目标：开环 Angle 或 FOC Ud/Id |
| 12 | `uint16` / `float32` | 开环角度步进；FOC 电流模式为电流环带宽（Hz），其后 2 字节保留；FOC 速度模式为速度斜坡速率（rpm/s，范围 1~100000）；位置模式保留 |

速度模式下，界面使用目标转速的正负号表示旋转方向。上位机下发目标转速绝对值和速度斜坡速率，并按照目标符号自动设置方向位。下位机在 1 kHz 速度环中生成斜坡目标，启动以及运行中修改目标转速时均按该速率平滑变化；停止和急停仍立即关闭输出。电机运行时修改速度斜率通过控制帧实时生效，停止时修改则同时通过参数帧写入，确保下一次参数回读保持一致。

## FOC 环路参数

读取参数使用 `0x11`，负载长度为 0。下位机返回 `0x12` 参数负载；上位机写入时也使用相同的 `0x12` 负载布局，长度为 44 字节：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint16` | 电流环带宽，Hz |
| 2 | `uint16` | 保留，写 0 |
| 4 | `float32` | 速度斜坡速率，rpm/s，参数未配置时为 0，配置范围 1~100000 |
| 8 | `float32` | 速度环 KP |
| 12 | `float32` | 速度环 KI |
| 16 | `float32` | 速度环积分项限幅，A，最大 5 A |
| 20 | `float32` | AB 滤波器带宽，Hz，范围 1~500 Hz |
| 24 | `float32` | 位置环 KP |
| 28 | `float32` | 位置环到位线性软化范围，度，范围 0~180，不大于角度死区时关闭 |
| 32 | `float32` | 位置环到位速度死区，rpm，范围 0~100，固件默认 20，写 0 时关闭 |
| 36 | `float32` | 位置环输出限幅，rpm |
| 40 | `float32` | 位置环角度死区，度，范围 0~180 |

下位机在电机停止时校验并应用参数。上位机离线时速度斜率保持 0，不预置设备参数；连接后先读取参数，界面以回读结果覆盖离线初值，速度斜率也采用下位机回读值。参数未同步前不得启动有感 FOC。全部有感 FOC 子模式还必须具备有效编码器零点参数，否则下位机拒绝使能并关闭输出。

电流和速度模式不再单独选择方向，目标值非负时 bit1 为 0，目标值为负时 bit1 为 1；开环和电压模式下 bit1 仍由方向选择控制。位置模式下该位改为回正方式：bit1 为 0 时按最近距离回正，也是上位机默认选项；bit1 为 1 时连续累计位置模式建立参考后的偏转角度，并沿偏转路径的反方向原路回正。例如顺时针偏转 270 度后，原路回正模式会逆时针返回 270 度，最近距离模式则顺时针返回 90 度。

位置环反馈使用扣除编码器零偏并修正编码器方向后的单圈机械角，按 `uint16` 单圈计数线性映射为 `0~360` 度，`360` 度与 `0` 度等价。最近距离误差展开到 `-180~180` 度；原路回正误差通过相邻位置环采样的最短角度增量连续累加，因此跨越 `0/360` 度时不会丢失偏转圈数。误差绝对值不超过角度死区时，位置环输出速度目标为 0；超出死区时先从误差绝对值中扣除死区宽度，得到有效误差。软化范围大于角度死区时，在角度死区边界至软化范围之间，位置 KP 比例按照 `|有效误差| / (软化范围 - 角度死区)` 从 0 线性恢复到完整增益；软化范围小于等于角度死区时关闭软化。

到位速度死区只在位置误差已经进入角度死区后生效。此时若实际转速仍高于速度死区，速度环继续以零速目标制动；实际转速进入速度死区后，清除速度 PI 状态并令 `Iq` 目标为 0，避免编码器零速噪声持续激励电机。位置误差离开角度死区后立即恢复正常位置和速度控制。

速度环 PI 输出由下位机按照 `sqrt(Imax² - Id²)` 计算出的 q 轴可用电流动态限幅，并将饱和误差反算给积分器。AB 滤波器带宽在速度环参数区设置，用于编码器转速反馈滤波。

上位机连接物理串口后以 20 Hz 周期发送该命令，同时兼作控制心跳。急停、停止等状态变化时不应等待下一周期，应立即额外发送一帧。

音乐模式不再使用单频频率和幅值参数。驱动模式为 2 时，偏移 3 为通过 `0x14` 乐曲列表获得的曲目编号；偏移 4 改按 `uint32` 解释为播放会话号，偏移 8 和 12 置零。上位机每次按下播放按钮都递增会话号。下位机仅在使能由关闭变为打开、曲目编号改变或收到新的会话号时从头播放；20 Hz 心跳中的相同会话号只能保活，不得重新触发曲目。乐曲节拍和播放过程全部由下位机负责，上位机不计算播放进度。

## 零点校准命令

`0x15`，负载长度为 0。下位机收到合法帧后先停止当前控制输出，再在主循环中执行桥臂自检和编码器零点校准。该命令是一次性触发命令，不随控制心跳重复发送；上位机仅允许在设备已连接、电机未运行且急停未锁定时发送。

## 内置乐曲列表

上位机打开物理串口后发送一帧负载长度为 0 的 `0x14` 查询。下位机按曲目编号顺序逐首返回 `0x14` 响应，每首乐曲占一帧：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 曲目编号，从 1 开始连续编号 |
| 1 | `uint8` | 下位机内置曲目总数 |
| 2 | `uint8` | UTF-8 曲名的字节数 M，当前最大 48 |
| 3 | `uint8[M]` | UTF-8 编码曲名，不带结尾 `\0` |

同一次查询的全部响应必须携带相同的曲目总数。上位机收齐全部编号后才一次性替换乐曲下拉列表；未收到响应或响应不完整时继续显示兼容列表。因此以后新增下位机曲目时，只需在下位机音乐表中维护曲名和旋律，上位机在重新连接后会自动同步。

## 基础遥测负载

`0x20`，56 字节：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint8` | 电机状态 |
| 1 | `uint8` | 当前控制模式 |
| 2 | `uint8` | 当前最高优先级故障 |
| 3 | `uint8` | 状态标志 |
| 4 | `uint32` | 设备运行时间，ms |
| 8 | `float32` | 斜坡处理后的目标转速，rpm |
| 12 | `float32` | 实际转速，rpm |
| 16 | `float32` | 目标 Id，A |
| 20 | `float32` | 实际 Id，A |
| 24 | `float32` | 目标 Iq，A |
| 28 | `float32` | 实际 Iq，A |
| 32 | `float32` | 母线电压，V |
| 36 | `float32` | 编码器机械角零点偏移，原始计数 |
| 40 | `float32` | 校正后的机械角度，°，范围 0~360 |
| 44 | `float32` | 电角度，° |
| 48 | `float32` | 估算转矩，N·m |
| 52 | `uint16` | U 相电流 ADC 原始采样值 |
| 54 | `uint16` | W 相电流 ADC 原始采样值 |

状态标志中 bit0 表示控制输出使能，bit1 表示电流采样已校准，bit2 表示下位机正在播放音乐。上位机观察到 bit2 从 1 变为 0 后，应立即发送失能控制帧并将播放按钮恢复为待机状态。

### 高速波形负载

`0x21`，36 字节单采样负载：

| 偏移 | 类型 | 字段 |
|---|---|---|
| 0 | `uint32` | 设备运行时间，ms |
| 4 | `float32` | A 相电流，A |
| 8 | `float32` | B 相电流，A |
| 12 | `float32` | C 相电流，A |
| 16 | `float32` | D 轴电压，V |
| 20 | `float32` | Q 轴电压，V |
| 24 | `float32` | PWM A，占空比百分比 |
| 28 | `float32` | PWM B，占空比百分比 |
| 32 | `float32` | PWM C，占空比百分比 |

当前驱动板默认每 10 ms 发送一个高速波形采样点；基础遥测仍按 25 ms 发送。该组合为 115200 bit/s 预留了协议与调度余量，可避免长期运行时因串口积压造成波形断点。高速波形和基础遥测共用帧序号，接收端应按负载中的设备时间戳排序。

## 下位机安全要求

- 连续 200 ms 未收到合法控制帧时关闭 PWM
- CRC、长度或协议版本错误的帧不得执行
- 急停优先级高于其他所有命令
- 参数范围必须由下位机再次检查
- PWM 频率、死区、极对数等参数只允许在电机失能时修改
- 接收中断只负责写入环形缓冲区，解析和命令处理放在主循环或低优先级任务
- FOC 电流环中断只写遥测缓冲区，不直接阻塞发送串口数据
